# Voice AI Agent for Egyptian Medical Polyclinics

A real-time, production-ready bilingual (Egyptian Arabic & English) Voice AI Medical Receptionist for doctor availability checks, appointment booking and management, grounded clinic knowledge retrieval (Hybrid Dense + BM25 RAG), and human receptionist escalation — built with LiveKit Agents, Deepgram Nova-3 STT, Groq / Gemini LLM Gateway, ElevenLabs Turbo v2.5 TTS, SQLAlchemy Async DB, and Qdrant Vector DB.
