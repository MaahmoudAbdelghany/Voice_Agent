before start any feature implemintation you must follow this rules : 

1. Read spec folder in root directory (mission, tech, roadmap) 
2. Identify next feature in roadmap.md
3. Ask clarification questions
4. Generate plan
5. Generate requirements
6. Generate validation
7. Wait for human review
